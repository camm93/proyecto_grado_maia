import pandas as pd
from sklearn.metrics import cohen_kappa_score, confusion_matrix
import seaborn as sns
import matplotlib.pyplot as plt

# 1. Cargar las etiquetas cruzadas
# Asumimos que tienes un CSV con las columnas correspondientes
df_cruce = pd.read_csv('validacion_cruzada.csv')

# Extraer las listas de etiquetas
anotador_1 = df_cruce['etiqueta_anotador_1']
anotador_2 = df_cruce['etiqueta_anotador_2']

# 2. Calcular el Kappa de Cohen General (Para las 8 categorías)
kappa_global = cohen_kappa_score(anotador_1, anotador_2)
print(f"Kappa de Cohen Global (8 Clases): {kappa_global:.4f}")

# 3. Matriz de Confusión Humana (Opcional pero muy recomendada)
# Esto le demostrará al profesor Manrique dónde están teniendo desacuerdos
etiquetas_unicas = ['INTRO', 'BACK', 'METH', 'RES', 'DISC', 'CONTR', 'LIM', 'CONC']
matriz_conf = confusion_matrix(anotador_1, anotador_2, labels=etiquetas_unicas)

plt.figure(figsize=(10, 7))
sns.heatmap(matriz_conf, annot=True, fmt='d', cmap='Blues', 
            xticklabels=etiquetas_unicas, yticklabels=etiquetas_unicas)
plt.title('Matriz de Confusión Inter-Anotadores')
plt.xlabel('Anotador 2')
plt.ylabel('Anotador 1')
plt.show()


###### INTERPRETACIÓN ############

¿Cómo interpretar el resultado para tu informe?
El resultado será un número entre -1 y 1. Para reportar este número en el documento final de su proyecto, se utiliza la escala estándar de Landis y Koch:

< 0.00: Desacuerdo (peor que el azar).

0.00 - 0.20: Acuerdo leve.

0.21 - 0.40: Acuerdo justo.

0.41 - 0.60: Acuerdo moderado.

0.61 - 0.80: Acuerdo sustancial (Este es el objetivo ideal para proyectos académicos de PLN).

0.81 - 1.00: Acuerdo casi perfecto.

El análisis cualitativo que pide el documento
Si tu Kappa da, por ejemplo, 0.68, en tu informe no solo pongas el número. Revisa la matriz de confusión que genera el código anterior y añade un comentario como este:

"Se obtuvo un Kappa de Cohen de 0.68 (Acuerdo sustancial). Al revisar los desacuerdos, identificamos que la mayor confusión ocurre entre las categorías INTRO y BACK. Esto se debe a que algunos artículos combinan la revisión del estado del arte dentro de la misma sección de introducción. Estos casos fueron resueltos mediante discusión para la conformación del conjunto de prueba final."
